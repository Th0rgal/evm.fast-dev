# R10 spec and persistent cache

Based on `ae2c240b83a9aa7d4af2d71a3ba479500e711f8e` on `wave8/spec-r10`.
This is a proposed specification with admitted leaves, not a verified certificate.

## Changes

Global frames quantify over byte-string keys outside `gw.map ofString`.
Function contracts require a successful entry lookup, including parameter shapes.
Empty intervals are disjoint and null/zero-capacity list intervals are normalized.
The world includes the `ws+16` nodedb table role. Every generated world contract
includes global-buffer writes from its full transitive call closure, including
local alias chains. `sk_buf` has a 52-byte write extent within its 64-byte allocation.
The buffer-separation glue is proved, including partial-buffer regions.

Header, request, transaction/access-list, message/frame, and receipt/log contracts
carry the decoder bounds and lifetime facts their callers need. Input ownership
includes transaction slots; the block guard retains their slice-length bounds and
header validity. `NodeHeap` bounds cached RLP and value lengths; four encoding
leaves move from the unconditional tier to node-heap guards.

Loop numbers in the override manifest are zero-based within each function.
Stride bounds count residues modulo `gcd(stride, 2^64)` over the complete index
range; they do not assume an arbitrary base starts a monotone sweep. The `fe_*`
and `execute_block` bounds use consecutive mandatory loads, which cannot cross
the invalid memory gap. `destroy_storage` uses a signed-counter bound of `2^63`:
its inner table can change, so a fixed-base walk is insufficient.

`K_pan` has 374 bits. The target has 121 decimal digits and is at most

## Validation

Lean v4.33.1 accepted the monolithic `GuestInv.lean` with `-M24576`
(exit 0, 44.01 seconds, peak RSS 9,827,120 KiB), and all 36 split modules
passed the same memory cap. All split source hashes match the recorded builds;
the port manifest matches the monolithic source hash. Conditional `assembly`
and `assembly_main` use only `propext`, `Classical.choice`, and `Quot.sound`.
Both budget theorems use only `propext`, with no `sorryAx` in the conditional
assembly or budget proofs.

The revision audit preserves all 723 retained `fb_*` declarations and `GuestInv`;
four node-encoding leaves are reclassified. Its census is 936 admitted theorem
bodies, all in the approved leaf categories. The transitive write audit covers
all 84 `wk_*` contracts with no missing globals or global-buffer regions.
`Guest.SoftwareAst`, `InitE.SourceFacts`, `InitE.SourceCodeFacts`, and
`InitECandidate.Proofs.BitmapInstallation` are prebuilt in the persistent cache.
The bitmap module passed `lean -j1 -M24576 -DElab.async=false` (exit 0,
72.79 seconds). Its two public installation theorems use only the standard
three axioms. `seed_bitmap.py` keeps the fixed source untouched and compiles a
cache copy with section-local irreducibility and generic list/ROM-reading proof
factoring, following the checked integration approach at `7d5ef0bc5c`.
The script checks that all original theorem statements are preserved.

Source hashes, compilation outcomes, bounds and axiom reports are recorded in
[R10_validation.json](R10_validation.json). No certificate verification or Yukon
submission is claimed.

## Snapshot layout

All persistent state is under `/var/lib/orb-node/caches/`, owned by `orbnode`:

- `repo/`: checkout, dependency cone and `.lake/build/lib/lean/` outputs.
- `elan/`: elan and Lean v4.33.1; `cargo/`, `xdg/`, `tmp/`: relocated tool caches.
- `downloads/wave8-cone-flapjack-initecandidate.tar.zst`: downloaded release cone.
- `GuestInv.olean`: monolithic spec artifact; `bitmap-prebuild/source/`: factored cache source.
- `r10-generated/`: generator outputs; `logs/`: compile and audit logs.
- `env.sh`: persistent tool paths; `lean-path.txt`: dependency search path.

Archive SHA256:
`e57619335600890bce4f43801c85a1d4fd1ebe2833dec71c7c9844b0c56b0369`.

Use `. /var/lib/orb-node/caches/env.sh` and
`export LEAN_PATH=$(cat /var/lib/orb-node/caches/lean-path.txt)` before invoking Lean.
The setup uses no `/home/orbnode` directory.
